# Boro Plugins

ARK plugins that go with [Boro](https://github.com/osTheDev/Boro), the PSP media player. Every shortcut is on the PSP's system buttons (NOTE and SCREEN), which games can't read, so no game loses a button.

| File | Plugin | Status |
| --- | --- | --- |
| `boro_bright.prx` | Better Bright: 10 brightness steps on SCREEN, SCREEN + Up / Down for one step, hold SCREEN 2 s to turn the screen off, optional full brightness on battery | Testing |
| `boro_status.prx` | Boro Status: battery % on the XMB, SCREEN + L for an in-game battery corner, SCREEN + Triangle peeks at the time and battery | Testing |
| `boro_hold.prx` | Hold+: HOLD shows a lock card then turns the screen off; nudge HOLD off and on for a peek; blocks an accidental sleep right after unlocking | Testing |
| `boro_snap.prx` | Snap: SCREEN + R saves a screenshot to `PICTURE/Screenshots/` without pausing the game | Testing |
| `boro_anywhere.prx` | Boro Anywhere | Planned |

## Install

1. Copy the `SEPLUGINS` folder to the root of the memory stick. It holds the plugins and `boro.ini`, the settings they share.
2. Open `SEPLUGINS/PLUGINS.TXT` (create it if it isn't there) and add one line per plugin. `always` loads it in the XMB, homebrew, UMD games and PS1 games:

   ```
   always, ms0:/SEPLUGINS/boro_bright.prx, on
   ```

   Boro's Settings > Plugins page writes these lines for you, and folds older `vsh` + `game` pairs into one line.

3. Restart the PSP.

To turn a plugin off, change `on` to `off` on its line, or use ARK's plugin settings in the recovery menu.

## If the PSP won't start

Take the memory stick out (or connect it to a computer) and set the plugin's lines in `SEPLUGINS/PLUGINS.TXT` to `off`. ARK's recovery menu can also turn plugins off.

## Settings

`SEPLUGINS/boro.ini` holds every plugin's settings in one file, one `[section]` per plugin. Boro's Settings > Plugins page will edit it; until then, edit it as text.

## Building

With the [pspdev](https://github.com/pspdev/pspdev) toolchain on the path, run `make`. The plugins and `boro.ini` land in `dist/SEPLUGINS/`. `common/` holds what every plugin shares: the settings reader, NOTE and SCREEN handling, and drawing over the screen. `common/font.h` is generated by `tools/makefont.py` from Silkscreen (SIL Open Font License, see `OFL-Silkscreen.txt`).
